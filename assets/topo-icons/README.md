# Topographic symbols

Original project SVG artwork on a 15×15 grid, supplementing the pinned Maki set.
Waterfall: vertical falling water; cascade: stepped falling water; arch: open
rock span; cave: dark entrance; spring: droplet and emergence lines; rock: crag;
pass: opposing slopes; shelter: open-sided roof. Natural features retain circular
frames; shelters retain square facility frames. Water symbols use blue ink.

Regenerate with `python3 assets/maki/build-icons.py`. Classification is applied
in the clients, including old downloaded tiles. Falls named “Cascade” or
“Cascades” use the stepped symbol; unnamed falls retain the waterfall symbol.
A spring symbol does not imply potable drinking water.
